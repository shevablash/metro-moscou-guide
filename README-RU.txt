ПУТЕВОДИТЕЛЬ ПО МОСКОВСКОМУ МЕТРО — ИНСТРУКЦИЯ

СОСТАВ ПРОЕКТА
- index.html — структура сайта.
- style.css — оформление и анимации.
- script.js — станции, видео, прогресс и логика разблокировки.
- assets/metro-map.png — предоставленная вами оригинальная схема.

ЧТО НУЖНО БУДЕТ ЗАМЕНИТЬ
Откройте script.js и найдите массив const STATIONS. Для каждой из 8 станций задаются:
- nameFr — название латиницей для французского туриста;
- nameRu — оригинальное название по-русски;
- descriptionFr — краткое описание по-французски;
- x и y — положение станции на изображении в процентах от 0 до 100;
- videoUrl — прямая ссылка на MP4. Пока оставьте пустую строку "".

ВНИМАНИЕ: текущие названия и координаты — демонстрационные. Они не соответствуют подтверждённому маршруту. Перед публикацией для туристов замените их на реальные.

ДОБАВЛЕНИЕ ВИДЕО ПОЗЖЕ
Пример: videoUrl: "https://адрес-хранилища/video-01.mp4"
Нужна прямая ссылка на видеофайл, а не ссылка на страницу просмотра/обмена. Хранилище должно разрешать браузеру получать файл и поддерживать HTTP Range для перемотки. Если videoUrl пустой, показывается заглушка. Для тестирования последовательности в этом режиме есть кнопка «MARQUER COMME TERMINÉ».

ФОТО ДЛЯ ВСТУПЛЕНИЯ
Сейчас используется CSS-заглушка. Поместите фото пустой станции в assets/intro-station.jpg. В style.css найдите .intro-photo и добавьте:
background-image: url("assets/intro-station.jpg"); background-size: cover; background-position: center;
Можно оставить градиентную подложку поверх фото.

КАК ПРОВЕРИТЬ НА WINDOWS
Можно открыть index.html двойным щелчком. Для удобной работы можно установить Visual Studio Code и расширение Live Server, открыть папку проекта и нажать Go Live.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Зайдите на https://github.com/ и войдите или создайте аккаунт.
2. Нажмите New repository. Название, например: metro-moscou-guide. Выберите Public и нажмите Create repository.
3. Распакуйте ZIP-архив на компьютере.
4. В созданном репозитории нажмите Add file → Upload files.
5. Перетащите index.html, style.css, script.js и папку assets (не сам ZIP-файл).
6. Нажмите Commit changes.
7. Откройте Settings → Pages.
8. В Build and deployment выберите Deploy from a branch.
9. Выберите ветку main и папку /(root), затем Save.
10. Через несколько минут адрес сайта появится в разделе Pages. Обычно он выглядит так: https://ВАШ-ЛОГИН.github.io/metro-moscou-guide/
11. При каждом последующем Commit changes GitHub Pages автоматически обновляет сайт.

ВАЖНЫЕ ОСОБЕННОСТИ
- Прогресс сохраняется локально в браузере посетителя и не синхронизируется между устройствами.
- Настоящее видео засчитывается автоматически только после полного просмотра (событие ended).
- Если закрыть видео до конца, станция не засчитывается.
- Завершённые станции можно пересматривать, будущие остаются заблокированными.
- Для тестирования без видео доступна кнопка ручного завершения этапа.
- Текущая вступительная сцена имеет временный CSS-фон; замените его фотографией станции, когда выберете изображение.
